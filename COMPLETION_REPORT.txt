🎛️ TECHNICAL DETAILS - التفاصيل التقنية:

Backend (خادم التطبيق):
  • Flask 3.0.0 - HTTP routing
  • PyTorch 2.1.2 - ML models
  • Bark TTS - singing synthesis
  • pydub 0.25.1 - audio processing
  • NumPy 1.24.3 - numerical computing

Frontend (واجهة المستخدم):
  • HTML5 - structure
  • Tailwind CSS - styling
  • JavaScript - interactions
  • Arabic support - full support

Logging (نظام التسجيل):
  • Python logging module
  • RotatingFileHandler
  • 10MB max file size
  • 5 backup files
  • Multiple log levels

Audio Pipeline (معالجة الصوت):
  • Bark generates audio arrays
  • NumPy converts to float32
  • pydub creates AudioSegment
  • Audio mixing with dB adjustments
  • MP3 export via FFmpeg
